## Step 1: 最初の投稿（アカウント作成の直後）

`out/x_posts/posts.md` に**そのまま貼れる文**、`out/x_posts/*.png` に**画像**を生成済み。
ツリー（スレッド）で7投稿。1投稿目を**固定ポスト**にする。

素材の作り直しは毎週これ:

```bash
cd ~/fba-trend-data && python scripts/generate_x_posts.py
```

### 投稿で守るルール

1. **リンクは最後の1投稿だけ。** Xはリンク付き投稿の表示を露骨に落とす
2. **画像は必ず付ける。** データ画像は保存・引用されやすい
3. **「登録してください」を言わない。** 最初の1ヶ月は価値提供だけ
4. 投稿時間は **月曜7:30 / 火21:00 / 木21:00**（副業層がスマホを見る時間）

## Step 2: 毎日15分の作業（これが本体）

投稿だけでは伸びない。**リプライが本体。**

### 毎日やること

1. 検索欄で `せどり 初心者` `物販 副業 始めた` `仕入れ 分からない` を検索、**最新**タブ
2. 直近24時間以内の投稿を10件開く
3. そのうち **3件に、具体的な数字入りでリプライ**

### リプライの型（売り込まない）

> 相手「せどり始めたけど何を仕入れればいいか分からない」

```
最初は品目を絞るのが早いです。
今週だとペット用品が動いていて、猫砂（ライオン ニオイをとる砂 5.5L×4袋 ¥3,600）が1位でした。
消耗品はリピートが読めるので初回向きです。
```

**ポイント**: 実データを1つ具体的に出す。宣伝は入れない。プロフィールを見に来させる。

### DMは相手が反応してから

新規アカウントのコールドDMは凍結リスクが高い。
**リプライに返信が来た相手にだけ**、以下を送る。

```
はじめまして。
さっきの件、毎週月曜にAmazonの売れ筋TOP10を5カテゴリぶんPDFにまとめてるので、
よければ今週ぶんお送りします（無料・登録不要）。
メールアドレスだけ教えていただければ送ります。

正直まだ始めたばかりのサービスなので、
受け取ったあとに「ここが使いにくい」を教えてもらえると本当に助かります。
```

> **最初の20人には無料で配る。** 売上より「なぜ要らないのか」の情報の方が今は価値が高い。
